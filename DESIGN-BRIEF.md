# Design Brief

## What this book is

A sibling book to *Wayward House Mathematics*, aimed at readers who have
followed the Grade 7 to university path and now want a mathematically honest
entry into data science, machine learning, and AI.

## What it is not

- not a programming manual
- not a framework guide
- not a shallow "math for ML" cram sheet
- not a list of algorithms with no geometric or statistical spine

## Core design principle

Every chapter should point backward into the main series and forward into a
learning-system idea. The reader should never feel that ML arrived from nowhere.

## Repeating visual threads

- objective landscapes
- data clouds and projection geometry
- distributions and posterior updates
- sequence and filter views
- information landscapes
- layer-by-layer function composition

## Minimum viable build

If the book is developed incrementally, the minimum viable first release should
be:

1. Mathematical modelling for data and systems
2. Statistical learning
3. Optimisation for machine learning
4. Linear algebra for representations
5. Neural networks and deep learning mathematics

The probability, information-theory, and sequence chapters can follow after
that, but the book will be stronger if they are treated as core rather than
optional.
